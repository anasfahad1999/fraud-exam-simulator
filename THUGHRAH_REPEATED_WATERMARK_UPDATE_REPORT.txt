تحديث العلامة المائية المتكررة داخل الاختبار

تم تعديل شاشة الاختبار في src/Simulator.tsx بحيث تظهر علامة مائية متكررة باسم المستخدم المسجل داخل خلفية شاشة الاختبار.

آلية العمل:
- تعتمد العلامة المائية على user.name من نظام تسجيل الدخول.
- إذا لم يتوفر الاسم، يستخدم النظام الجزء الأول من البريد الإلكتروني كاحتياط.
- إذا لم تتوفر بيانات مستخدم، يظهر النص الافتراضي: متدرب ثغرة.
- العلامة متكررة على كامل شاشة الاختبار وليست علامة واحدة.
- العلامة خفيفة جدًا ولا تعيق قراءة السؤال أو الخيارات.
- لا تظهر داخل صفحة البداية أو النتائج؛ التركيز الحالي على شاشة الاختبار نفسها.

الهدف:
تقليل احتمالية تسريب لقطات شاشة بدون أثر، وربط أي صورة مسربة باسم المستخدم الظاهر داخل الاختبار.

الفحص:
تم تنفيذ فحص TypeScript بنجاح عبر npx tsc --noEmit.
تم إنشاء ملفات البناء عبر Vite، لكن أمر البناء توقف عند مرحلة عرض حساب gzip في بيئة التنفيذ بعد توليد dist، لذلك يُفضّل إعادة تشغيل npm run build محليًا بعد فك الضغط للتأكد في جهازك.
