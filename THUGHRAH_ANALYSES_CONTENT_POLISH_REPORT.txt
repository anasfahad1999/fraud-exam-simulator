تقرير تعديل صفحة التحليلات ومحتوى قضية Enron

ما تم تنفيذه:
1. إعادة بناء عرض قضية Enron بالكامل كصفحة قراءة مستمرة بدل التنقل بين أقسام منفصلة.
2. ضبط عرض النص ليكون داخل عمود قراءة مريح، مع فهرس جانبي على الشاشات الكبيرة.
3. تحويل Timelapse إلى إضافة بصرية هادئة ومختصرة لا تقطع المحتوى ولا تعمل كفصل مستقل.
4. إعادة تهذيب صفحة التحليلات: مقدمة أوضح، بطاقات أكثر اتزانًا، وتصنيف أقل ازدحامًا.
5. جعل Enron هو التحليل البارز القابل للفتح بدل إبراز مادة غير مفعّلة.
6. لم يتم تغيير النص الأصلي لقضية Enron، وإنما تغيرت طريقة عرضه فقط.

تشغيل النسخة:
npm install
npm run dev

7. تم جعل تعمية JavaScript اختيارية عبر ENABLE_OBFUSCATION=true لأن النص الطويل داخل التحليلات يجعل البناء أبطأ جدًا إذا تمت تعميته بالكامل. الوضع الافتراضي الآن أسرع وأكثر استقرارًا للنشر.
