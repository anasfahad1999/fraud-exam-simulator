تقرير تعديل موقع ثغرة — نماذج التدريب

المنفذ:
- حذف بيانات نماذج التدريب السابقة من ملف trainingQuizData.ts واستبدالها بالكامل ببيانات الملف الأخير: مواضيع الاختبار (2).zip.
- ترك المحاكي الرئيسي كما هو بدون تعديل على Simulator.tsx أو quizData.ts.
- تفريغ الأسئلة، الخيارات، الإجابات الصحيحة، والشرح من ملفات Word داخل المواضيع.
- إضافة المحاور داخليًا لكل سؤال، واستخدامها في تقرير نهاية النموذج بدل إظهارها أثناء الحل.
- إضافة شاشة تقرير تفاعلية بعد إنهاء النموذج تعرض:
  1) الدرجة والنسبة وحالة الاجتياز.
  2) المحاور التي أُنجزت بلا خطأ.
  3) المحاور التي تحتاج مراجعة عند وجود أخطاء.
  4) الأسئلة الخاطئة مع إجابة المستخدم، الإجابة الصحيحة، والشرح.
  5) تبويب لعرض الأسئلة الخاطئة أو كل الأسئلة.
- تحديث عدادات التدريب داخل الموقع لتظهر عدد النماذج والأسئلة تلقائيًا.
- تحديث بناء dist الجاهز للنشر.

- عدد الأسئلة المفرغة: 680
- عدد مشاكل التفريغ الفنية المتبقية: 0

ملاحظات مهمة:
- بعض ملفات Word لم تكن تحتوي على جدول محاور صريح؛ تمت إضافة محاور داخلية لها بناءً على نطاق الأسئلة حتى لا يخرج التقرير النهائي فارغًا أو عامًا جدًا.
- بعض النماذج ما زالت فيها ملاحظات جودة سابقة مثل عدم توازن الإجابات، لكنها تُركت كما طلبت دون تعديل محتوى السؤال أو الإجابة.
- ظهر تحذير Vite بأن ملف JavaScript النهائي أكبر من 500KB بسبب حجم بنك الأسئلة، لكنه تحذير أداء وليس فشلًا في البناء.
- لا ترفع node_modules إلى GitHub.

طريقة النشر المقترحة:
1) استخدم ملف dist الجاهز للنشر إذا كنت سترفع مباشرة على GitHub Pages.
2) أو استخدم ملف المصدر، ثم نفذ:
   npm install
   npm run build
   ثم ارفع محتوى dist.
